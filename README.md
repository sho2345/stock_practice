# 📈 はじめての株シミュレータ

株を知らない人でも、**本物の株価データ** を使って、お金を使わずに株の売買を体験できる Web アプリです。

👉 **https://hajimete-kabu.streamlit.app/** （Google アカウントでログインして使えます）

## できること

- **⏳ タイムマシンモード**：2005年以降の好きな時点にタイムスリップし、時間を早送りしながら投資を体験
- **📡 リアルタイムモード**：今日の株価で売買し、数か月後・数年後の結果を確かめる
- 日本株・米国株・ETF の **50銘柄** から、いくつでも購入可能（米国株はドル円レートで円に換算）
- 資産の推移・銘柄ごとの値動き・日経平均や S&P500 との成績くらべをグラフで表示
- 「株の基礎知識」「アプリの使い方」のマニュアル付き
- 売買の記録はアカウントごとに保存され、スマホと PC のどちらからでも続きを遊べます

## 使っている技術

Python / [Streamlit](https://streamlit.io/)。株価は [yfinance](https://github.com/ranaroussi/yfinance) を使って Yahoo! Finance から取得しています。
