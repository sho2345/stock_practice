## このアプリについて

**実際の株価データ** を使って、お金を使わずに株の売買を体験できるシミュレータです。
「買った株が何か月後・何年後にいくらになるか」「全体でどれくらいの収支になるか」を確かめながら、株の感覚を身につけることを目的としています。

株のことがまったく分からない人は、先にホーム画面左下の **「📗 株の基礎知識」** を読むのがおすすめです。

## 2つのモード

| | ⏳ タイムマシンモード | 📡 リアルタイムモード |
|---|---|---|
| どんなもの | 過去の好きな時点（2005年〜）に戻って、そこから時間を早送りしながら投資する | 今日の株価で買い、実際に時間が経つのを待って結果を見る |
| 時間の進み方 | ボタンで「1か月」「1年」などと進める | 現実の時間と同じ |
| 向いていること | 暴落・回復・長期保有などの値動きの感覚を短時間でつかむ | ニュースや決算をもとに自分で判断する練習 |
| 株価 | 各月の月末の終値 | 最新の株価（取引時間中は約20分遅れ） |

どちらのモードも、最初に **元手（初期設定は100万円）** を決めて始めます。

## 使い方

ホーム画面でモードを選ぶと、そのモードが始まります。ページ上部の「🏠 ホーム」でいつでもホーム画面に戻れます。

### ⏳ タイムマシンモード
1. 初回は「株価データをダウンロードする」を押します（数十秒かかります）
2. 開始する年月と元手を決めて、スタートのボタンを押します
3. 「🛒 株を買う・売る」タブで、気になる銘柄の「詳しく見る・売買」を押し、株数を決めて買います。**いくつの銘柄でも買えます**
4. 画面上部の黒いパネルの「▶ 1か月」「🚀 1年」などのボタンで時間を進めます
5. 「📊 ポートフォリオ」タブで、資産の推移や銘柄ごとの値動きを確認し、売り買いを繰り返します
6. ゴール（データの最後の月＝先月）に着くと、最終結果が表示されます

### 📡 リアルタイムモード
1. 元手を決めて、スタートのボタンを押します
2. 「詳しく見る・売買」の画面にある「📰 この会社のニュース・業績を見る」から企業の情報を調べ、買う銘柄を決めます
3. 数日後・数か月後にアプリを開くと、その日の株価で資産が計算されます
4. アプリを開いた日ごとの資産が記録され、推移グラフになります

## 画面の見方

### 上の数字のタイル
- **総資産**：現金と、持っている株を今の株価で計算した金額の合計
- **合計の損益**：元手からいくら増えたか（減ったか）。内訳として次の2つも表示します
  - **含み損益**：まだ売っていない株の、今売った場合の損益
  - **確定損益**：もう売った株で、確定した損益
- **株の評価額**：持っている株を今の株価で計算した金額
- **成績くらべ**：同じ元手で最初に日経平均や S&P500 に全額投資していた場合と、あなたの成績を比べます

### 📊 ポートフォリオ（持っている株）
- **資産の推移**：あなたの資産（青い実線）と、指数に全額投資した場合（破線）の比較。グラフにマウスを乗せると、その時点の金額が見られます
- **資産の内訳**：現金とそれぞれの銘柄が、資産の何割を占めているか
- **銘柄ごとの値動き**：買い始めた時点を 0% として、各銘柄がどれだけ上がったか（下がったか）を比較します
- **持っている株**：銘柄ごとのカード。株数・平均取得単価（買った値段の平均）・評価額・損益と、買ってからの株価の小さなグラフ

同じ銘柄は、どのグラフでも同じ色で表示されます。

### 🛒 株を買う・売る
全50銘柄のカードが並びます。「日本株」「米国株」「ETF」で絞り込めます。カードの「前月比」「前日比」は、1か月前（1日前）からの株価の変化です。

### 📜 取引履歴
これまでの売買の記録と、売却して確定した損益の合計です。

## 売買できる銘柄

日本株28社、米国株19社、ETF 3つ（日経平均・S&P500・ナスダック100 に連動するもの）の合計50銘柄です。キオクシアやパランティアなど、最近話題の銘柄も入っています。
タイムマシンモードでは、選んだ時点でまだ上場していない銘柄（例：2012年より前の Meta）は買えません。

## 現実との違い（簡単にするためのルール）

- **1株から売買できます**（実際の日本株は通常100株単位ですが、1株単位で買えるサービスもあります）
- **売買手数料と税金はかかりません**
- 注文は必ず表示されている株価で成立します（成行注文で、すぐ成立するイメージ）
- 米国株は、その時点のドル円レートで円に換算して売買します（両替の手数料はなし）
- **タイムマシンモード** の株価は配当と株式分割を反映した「調整後株価」です。配当を受け取って、そのまま同じ株を買い増した扱いになります
- **リアルタイムモード** では配当は反映されません。株式分割があった場合は、株数を自動で調整します
- リアルタイムモードでは、市場が閉まっている時間（夜間や休日）でも直近の終値で売買できます

## データの保存について

- データベースは使っていません。売買の記録は、このアプリのフォルダ内の `data/saves/` に JSON ファイルとして保存されます
- タイムマシンモードの株価データは `data/prices_monthly.csv` に保存されます。新しい月のデータを追加したいときは、タイムマシンモードの設定画面にある「株価データを更新する」を押してください
- 各モードの「最初からやり直す」を押すと、そのモードの記録が消えます
- 株価は Yahoo! Finance のデータを、yfinance というツールを使って無料で取得しています。まれに取得に失敗することがあります。その場合は時間をおいて再度お試しください

## 起動方法

アプリのフォルダにある **`起動.bat` をダブルクリック** すると、黒い画面が開き、少し待つとブラウザでアプリが表示されます。黒い画面を閉じるとアプリも終了します（初回だけ、必要なライブラリのインストールに数分かかります）。

コマンドで起動する場合（開発者向け）：

```
.venv\Scripts\activate
streamlit run app.py
```

> ⚠️ このアプリは学習用のシミュレータです。表示される内容は、特定の銘柄の売買をすすめるものではありません。
